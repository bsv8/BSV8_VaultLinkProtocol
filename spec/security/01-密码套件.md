# 01 密码套件 `vlp-suite-v1`

> VLP 0.1 Draft · 决策见 [D-003](../../decisions/0003-冻结决策.md)、
> [D-004](../../decisions/0003-冻结决策.md)、[D-017](../../decisions/0003-冻结决策.md)。

## 1. 原则

VLP **不新造密码方案**。全部选用已有标准与已有成熟实现（mbedTLS、
Node WebCrypto、OpenSSL、libsodium）。所有向量必须由**真实密码实现执行**得出，
不得以 grep 源码常量充当通过。

## 2. 原语

| 用途 | 选定 | 标准 | 维护实现来源 |
| --- | --- | --- | --- |
| 临时密钥协商 | X25519 | RFC 7748 | libsodium / mbedTLS / Node WebCrypto |
| 密钥派生 | HKDF-SHA256 | RFC 5869 | 同上 |
| 记录加密 | AES-256-GCM（96 位 nonce，128 位 tag） | NIST SP 800-38D | 同上 |
| 摘要 | SHA-256 / SHA256d | FIPS 180-4 | 同上 |
| HMAC | HMAC-SHA256 | RFC 2104 / FIPS 198-1 | 同上 |
| 业务签名 | ECDSA secp256k1，RFC 6979 确定性 nonce | RFC 6979 | libsecp256k1 / mbedTLS / noble |
| 口令派生 | PBKDF2-HMAC-SHA256 | RFC 8018 | 同上 |
| 地址 | RIPEMD-160、SHA-256、Base58Check | — | mbedTLS / OpenSSL |

**验收要求**：负向向量必须**确定失败**；正向向量必须**实际执行实现**，
不能只检查常量存在（[0002](../../decisions/0002-差异清单.md) §6 G4/G5）。

## 3. 已知禁用行为

| 禁用 | 理由 |
| --- | --- |
| 让设备直签主机给的 32 字节 | 退化成「签任意摘要」，交易摘要可当 challenge 换走等效签名 |
| 隐式二次 hash | 既有业务（BSV8 Channel、BIP143）都要求 `prehash: false` |
| 静默截断 PBKDF2 salt | 现有实现把 >64 字节 salt 截到 64，无声改变派生结果 |
| 用全零输出代替算法失败 | 失败必须显式失败 |
| 用时间戳当授权 ID | 会话内碰撞，且时间可被主机影响 |
| 自创密钥协商替代既有 Channel | 见 [D-014](../../decisions/0003-冻结决策.md) |

## 4. 域标签清单

所有跨用途的声明摘要使用域标签。构造形式见
[02-编码.md](../core/02-编码.md) §6：`SHA256d(label ‖ 0x00 ‖ fields)`，
`0x00` 只作分隔符，末尾不加。

### 4.1 协议内声明（`vlp:` 前缀，VLP 新增）

| 标签 | 字节数 | 用途 | Profile |
| --- | --- | --- | --- |
| `vlp:handshake:v1` | 16 | 握手 transcript | Core |
| `vlp:link:pairing:v1` | 19 | 配对码 | Core |
| `vlp:link:c2s:key:v1` | 19 | c2s 方向密钥 | Core |
| `vlp:link:c2s:nonce:v1` | 21 | c2s 方向 base nonce | Core |
| `vlp:link:s2c:key:v1` | 19 | s2c 方向密钥 | Core |
| `vlp:link:s2c:nonce:v1` | 21 | s2c 方向 base nonce | Core |
| `vlp:possession:v1` | 17 | 持有权证明 | Core |
| `vlp:commit:v1` | 13 | 请求承诺 | Core |
| `vlp:identity:prove:v1` | 21 | 身份证明声明 | Identity |
| `vlp:identity:authorize:v1` | 25 | 身份/意图授权声明 | Identity |
| `vlp:content:v1` | 14 | 内容摘要声明 | Content |

### 4.2 兼容 wire（不改）

| 来源 | 摘要规则 |
| --- | --- |
| BSV8 Channel | `SHA256(JCS({scope, channel, from_public_key, message}))`，scope = `bsv8.public-message.v1` / `bsv8.private-message.v1` / `bsv8.hash-request.v1` |
| BSV8 私密信封 | HKDF info = `JCS({scope:"bsv8.inbox.envelope.v1", channel, from_public_key})` |
| BSV P2PKH | BIP143 sighash，`SIGHASH_ALL|SIGHASH_FORKID = 0x41` |
| Keymaster Local Secret v3 | HKDF salt `keymaster.vault.local-secret.v3`，AAD `keymaster:local-secret:v3\|scope` |
| Keymaster Forum | 既有确定性 CBOR 定长数组 + 单次 SHA-256 |

**新增 `vlp:` 域标签不得改变以上任何既有签名的字节**（[D-017](../../decisions/0003-冻结决策.md)）。

## 5. 记录加密参数

见 [03-帧与消息.md](../core/03-帧与消息.md) §4。摘要要点：

| 项 | 值 |
| --- | --- |
| 算法 | AES-256-GCM |
| 密钥长度 | 32，方向分离 |
| nonce | 12 = `baseNonce[dir] + counter[dir]`（96 位大端加法） |
| tag | 16，附于密文尾部 |
| AAD | 10 字节：`type(1) ‖ flags(1) ‖ seq(u32 BE) ‖ deviceRunId(u32 BE)` |
| 计数器推进 | **仅认证成功时**；`2^64−1` 时必须重建连接，不回绕 |
| 失败处理 | **中止连接**，禁止继续使用错位链 |

## 6. 签名参数

| 项 | 值 |
| --- | --- |
| 曲线 | secp256k1 |
| 摘要输入 | 调用方提供 32 字节；**设备不隐式二次 hash** |
| nonce | RFC 6979 确定性（HMAC-SHA256） |
| S 值 | **low-S 归一化**（`s > n/2` 时 `s := n − s`） |
| DER 编码 | strict DER，8–72 字节，仅短形式长度 |
| compact | `r ‖ s` 64 字节，**不带恢复 ID** |
| 格式 | DER 与 compact **显式二选一**，响应中回报所用格式 |

### 6.1 strict DER

```
0x30 <len>
  0x02 <len_r> <r>
  0x02 <len_s> <s>
```

- 整数去前导零；仅当首字节最高位为 1 时补单个 `0x00`。
- **只允许短形式长度**；`0x80` 位置（长形式）一律拒绝。
- 无尾随字节。

## 7. 自检要求

设备与 SDK 的启动自检**必须**包含：

| 项 | 要求 |
| --- | --- |
| X25519 | RFC 7748 §5.2 向量 + §6.1 低阶点拒绝 |
| HKDF | RFC 5869 A.1 与 A.3 向量 |
| AES-GCM | 与成熟实现（mbedTLS/OpenSSL）逐字节差分，覆盖多组 aad/pt 长度 |
| RIPEMD-160 | ISO/IEC 10118-3 向量 |
| **ECDSA 签名与验签** | **必须实际签名并验签** |

> 现有固件的 `SelfTest()` 只测 X25519、local-secret、AES-GCM、RIPEMD-160，
> **从不签名或验签**；且用一个故意无效的签名调用 `VerifyDer` 并忽略结果
> （[0002](../../decisions/0002-差异清单.md) §6 G6）。
> VLP 要求任何自检失败都**阻止业务执行**。

**任何自检失败 → 套件错误显式阻止业务执行**，不得用全零或未初始化输出继续。

## 8. 秘密生命周期

| 规则 | 内容 |
| --- | --- |
| 清理 | 临时私钥、派生密钥、ECDH 中间值、明文缓冲在退出作用域时清理 |
| 持久化 | **仅**设备内部 PIN 封装密钥可落盘 |
| 不落盘 | 通信密钥、nonce 链、承诺、审核上下文 |
| 失败路径 | 算法失败时清理已产生的中间值 |
| 日志 | 不输出私钥、PIN、口令、密码或可推导它们的材料 |
