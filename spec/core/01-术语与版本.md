## 1. 名称与缩写

| 术语 | 含义 |
| --- | --- |
| VLP | VaultLink Protocol，密钥设备互操作协议 |
| 主机 host | 运行 SDK 的应用侧（浏览器页面、Worker 或未来其它宿主） |
| 设备 device | 持有业务私钥的密钥设备 |
| 业务 Key | 当前唯一的 secp256k1 业务身份密钥（首版基线） |
| 业务公钥 | 业务 Key 的 33 字节压缩公钥 |
| Profile | 一组语义相关操作的规范：字段、承诺、验证、审核、授权、结果 |
| Core | 与传输和 Profile 无关的协议层：身份绑定、会话、请求、授权、结果、事件 |
| grantScope | 从实际操作提取的语义授权范围，用于持续决定匹配 |
| requestCommitment | 对本条请求规范编码的密码学承诺，仅绑定本条请求 |

**命名隔离**（需求 §5.1）：业务 Key、临时通信密钥、方向密钥、设备内部 PIN 封装密钥
分别命名，本文与规范全文不混用。

| 名称 | 用途 | 生命周期 |
| --- | --- | --- |
| 业务身份密钥 | 产生业务签名 | 长期；跨迁移保持不变 |
| `hostEphemeral` / `deviceEphemeral` | 临时密钥协商 | 单次握手 |
| `c2sKey` / `s2cKey` | 方向分离的记录密钥 | 单条认证连接 |
| PIN 封装密钥 | 设备内部保护业务私钥 | 设备内部；**不进 VLP** |

**禁止**：普通操作导出业务私钥或长期派生密钥；PIN 在设备输入，
VLP 不提供主机代输或模拟按键入口。

## 2. 字段表

`u32` 为无符号 32 位整数。世代类字段由主机生成，重启/迁移后必然不同。

| 字段 | 类型 | 宽度 | 生成者 | 作用域与生命周期 |
| --- | --- | --- | --- | --- |
| `identity` | bytes | 33 | 设备 | 业务压缩公钥；稳定 |
| `publicKey` | bytes | 33 | 设备 | 同 `identity`，wire 用名 |
| `deviceRunId` | u32 | 4 | 设备 | **每次设备启动重新随机**；非 0 |
| `connectionId` | bytes | 16 | 设备 | 单条认证连接；重连不同 |
| `hostRunGeneration` | u32 | 4 | 主机 | 主机每次运行重新随机 |
| `walletGeneration` | u32 | 4 | 主机 | 钱包身份世代；注销重建必不同 |
| `backendGeneration` | u32 | 4 | 主机 | 后端绑定世代；**同 Key 迁移也必不同** |
| `sessionId` | u32 | 4 | 主机 | App/主机会话标识 |
| `sessionEpoch` | u8 | 1 | 设备 | 会话代际；1–128，重开会话必不同 |
| `requestId` | u32 | 4 | 主机 | 连接/会话内唯一；重放检测 |
| `requestCommitment` | bytes | 32 | 主机 | 每条请求必填；非全零 |
| `decisionRevision` | u32 | 4 | 设备 | 授权修订；任何持续决定变更即推进 |
| `eventSeq` | u32 | 4 | 设备 | 运行世代内单调递增，从 1 开始 |
| `migrationId` | bytes | 16 | 主机 | 迁移标识；**不含任何秘密** |

### 2.1 溢出与重启规则

| 规则 | 内容 |
| --- | --- |
| 世代随机数 | 主机/设备的每个 `*RunId`/`*Generation` 为随机 u32，**不得为 0**；生成后本地保持不变 |
| 计数器推进 | `sessionEpoch` 为 `u8`，取值 1–128；`eventSeq` 溢出（超过 2^32−1）时设备必须重启运行世代而非回绕 |
| 世代变化清授权 | `hostRunGeneration`、`walletGeneration`、`backendGeneration`、`deviceRunId`、`connectionId` 任一变化 → **清空全部持续决定并推进 `decisionRevision`** |
| 金额累加 | 累加前检查 `a > UINT64_MAX − b`；溢出视为超限拒绝，不允许回绕（D-007） |
| `requestId` 空间 | 连接/会话内单调不重复；设备缓存满时返回 `busy` 而非淘汰（D-011） |

### 2.2 身份不得由弱凭据替代

设备编号、USB `VID:PID`、序列号、主机名称、域名、主机自述 `verified`
**都不是身份凭据**。身份 = 业务公钥 + 持有权证明（[04-握手与链路](./04-握手与链路.md) §5）。

主机世代是**绑定材料**，不是主机身份已认证的证据。

## 3. 分层

```
应用（Keymaster Vault / 其它客户端）
  业务 Profile：Identity / BSV P2PKH / Channel / Local Secret / Content / Migration
    VLP Core：身份绑定、会话、请求、授权、结果、事件
      认证连接与消息层
        USB Serial 传输适配
```

Core 与字节传输解耦（[D-019](../../decisions/0003-冻结决策.md)）。传输规范、传输能力与
传输验收独立，不默认为已支持。

### 4.1 兼容矩阵

| 主机 Core | 设备 Core | 结论 |
| --- | --- | --- |
| 0.1 | 0.1 | 支持 |
| 0.1 | ≠ 0.1 | `version-mismatch`，链路关闭，不降级 |
| ≠ 0.1 | 0.1 | 主机侧拒绝连接 |

Profile 版本独立协商：设备必须先声明支持的操作及其 Profile 版本，
主机才能请求。**能力声明绑定 Profile 版本、支持的操作/格式/限额和授权方式**，
不宣称未能执行或未通过测试的能力（D-009）。

## 5. 不属于本规范

以下另立规格，不在 0.1 实现门禁内：其它传输（除 USB Serial）、多 Key/多链、
复杂 BSV 资产、更多证据服务、FIDO/CTAP2、远程设备、硬件认证/安全元件、治理组织。

本规范只定义 **USB Serial / Web Serial** 适配，不增加 HID、BLE、网络。
