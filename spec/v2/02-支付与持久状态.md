# v2 支付核算与设备持久状态

日期：2026-10-09。用户已确定：只按输出计费，矿工费不占额度。普通 P2PKH 对外输出合计为 amount，本 Key 找零根据实际脚本识别并排除，矿工费另列基础事实。单笔与 App 会话累计均用整数 satoshi/uint64。费用池只能按经核验的对外付款新增量核算；完整费用池阶段尚未选定，SDK 不提供费用池签名能力。

## 已实现的内部契约

PaymentPolicy 是唯一执行权威，通过 PolicyStore 原子保存快照；不能由主机输入 `withinLimit=true` 放行。App/plugin owner 与业务 sessionId 由可信适配层提供，支付 body 不接受自报 owner/已花金额。**渠道配置与 App 会话建立目前是 SDK 内部 API，尚未冻结/实现 USB 同步操作；不得宣称完整 P0/P1 已交付。**

ChannelConfig：`id, owner, kind:app|plugin, network, paymentType, enabled, singleLimit:bigint, defaultSessionLimit:bigint, revision:uint32`；绑定当前 Key。既有渠道 owner/kind/network/type 不可改写，revision 严格 +1。首次登记、启用、提高单笔/默认累计额度须执行端确认；降低/撤销使未执行旧批准失效。

App Session：`id,owner,limit,used,revision,active`。同一 App 多渠道合并一个累计额度，默认额度配置冲突时拒绝开会话。新会话须确认，不准主机复用 ID。插件不创建累计会话。

Pending：`id,sessionId|null,channelId,amount,commitment,configRevision,sessionRevision,state`，其中 state 为 reserved/signed/unknown/released。预占先落盘，再签名；同 ID 永不二次预占/签署。仅确定未执行时可转 released 并释放占用，保留墓碑；已签与未知均不释放。不以广播成功作为计额条件。

快照为 `{version:1,key:compressedPublicKeyHex,channels,sessions,pending}`，仅用于执行端内部存储，不是主机可任意恢复的 USB 输入。载入时校验 Key/引用/修订/计数一致性；任何失败停止自动支付，禁止内存回退。宿主必须提供防回滚、抗损坏、原子写入的真实设备存储；Node 文件适配只能用于参考实现，不能替代 ESP32 安全存储。

`quote` 同时列出 disabled/single-limit/session-limit；等于额度自动执行。超额 approval 绑定 requestCommitment、configRevision 和 sessionRevision。一次批准不改额度、不清 used；raiseSessionLimit 只改当前累计额度，并须足够覆盖 used+amount，不改未来默认或单笔额度。授权到执行之间再次检查配置/会话修订。

安全容量为 32 渠道、16 个保留会话、256 条支付记录、持久编码最多 64 KiB。达到容量明确拒绝，不自动淘汰重放证据。**当前没有安全归档/回收协议；持续运行的产品接入需解决这项容量阻断，不能静默删除记录或重置预算。**

## P2PKH 实施范围

操作注册建议名 `bsv.pay`，handler profile=`bsv-payment`、version=1。
body=`{rawTx:bstr,prevTransactions:bstr[],channelId:text,paymentId:text}`；核验核心另加设备计算的 `amount:uint64`，主机计算承诺时必须使用相同解析规则。结果=`{signatures:bstrDERWith41[],amount:uint64}`。

仅 legacy 交易、所有输入由当前 Key 所有、空 scriptSig、全部输出 P2PKH、SIGHASH_ALL|FORKID=0x41。完整前序交易必须与 outpoint txid/vout 字节绑定；拒绝重复输入、错误 Key、未知脚本及负矿工费。目标最多 640 字节/4 输入/6 输出，前序单份最多 8192 字节，但整个 USB 信封仍须 <=896，故当前只能传很小的实际交易；没有压缩/分片/输入证明替代路径。真实链上已确认/未花费状态由 Keymaster 负责，设备不声称验证网络共识。

设备从实际对象解释收款输出、找零、矿工费及超限原因；信用信息和业务叙述归 Keymaster。签名交付前写入 signed；写入失败不交付、不释放预占。尚未支持费用池、Channel、Local Secret、导入导出与 PIN 流程，未知操作返回 unsupported。
