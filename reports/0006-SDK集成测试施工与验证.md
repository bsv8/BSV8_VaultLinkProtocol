# SDK 集成测试施工与验证

日期：2026-10-09。版本 `@vaultlink/sdk@0.2.0-draft.1` / wire 2。本报告补充 0005 当时的部分实现状态，不覆盖历史报告。工作区已有未提交修改；本轮未提交、发布或修改 Keymaster/RocKey 产品代码。

## 交付

独立 `integration/web`、`integration/esp32`、`integration/runner`、`integration/native` 子项目及共同 20 项序列。USB 适配属于 SDK，Demo 不复制协议。补充 `device/sdk` 的 C++ CBOR、实际密码、P2PKH、App 持久额度、Endpoint 和 Arduino 串口适配。

C++ 与 TS 实际执行完整握手、X25519/HKDF/AES-GCM、身份持有证明和 P2PKH 签名；由独立 Noble 验签，核算外部输出，不计矿工费。原生进程使用 ASan/UBSan，实际文件提交后复制交给 TypeScript 恢复核查。ESP32 调用实际 NVS 与 `esp_restart()`，测试授权脚本无需人工介入。

配对回调由产品显式提供；Demo 才自动批准。断链时 SDK 锁定密钥；公开测试密钥的重新加载在 Demo 中。测试控制入口受编译宏隔离，生产模式独立编译检查确认接口不存在。

## 未验收边界

其他 ESP32 板型、原生 CDC、物理断电时 Flash 行为未验收。内部重启验证业务恢复，不等价供电中断测试。PIN、屏幕、三按钮或实体人工批准未验收。

C++ 当前互通为 mainnet/App/P2PKH。测试中的渠道配置/故障控制不是生产渠道同步操作标准。插件渠道、费用池、迁移和其他 Profile 保持未实现/未验收；896 字节明文及有界账本限制不变。

本次独立 SDK 集成测试施工及当前目标板 USB 验收完成；未把上述产品/电气专项检查勾为完成。
