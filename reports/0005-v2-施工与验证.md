# VLP v2 施工与验证记录

日期：2026-10-09。用户授权本仓库代码施工；用户补充“只按照输出计费，不计算矿工费”，并要求考虑无电池硬件断电重连。本次未修改 Keymaster 或 RocKey 产品代码，未发布/刷机。

## 已交付

代码位于 `Coding/BSV8_VaultLinkProtocol`，包版本 0.2.0-draft.1，wire=2；不兼容旧 wire、不自动降级。

- TypeScript 严格 CBOR/帧解析、真实固定密码套件、全握手 transcript、配对码与受限 Key 持有权证明。
- WebSerial 适配、加密客户端/设备参考运行器、控制请求、单活动业务与最近结果/请求水位、未知不自动重发。
- PaymentPolicy：配置修订与 Key/owner 绑定、单笔/App 同会话跨渠道累计、并发预占、超额批准/当前会话增额、原子存储失败停止放行。
- 实际 P2PKH 前序交易/脚本核验及受限 DER 0x41 签名，独立计算对外输出/找零/矿工费；只对外输出占额度。
- 真实 Node 临时文件/fsync/rename/目录 fsync 存储参考；与额度/P2PKH 执行器联动，签名交付前提交 signed，失败不释放。
- 无电池重载逻辑：渠道保留、旧 App 会话 inactive、旧 reserved 转 unknown、金额占用与付款墓碑保留，不能续签/重放。带电池最小模式同样断链锁定。
- 无动态分配 C++ 帧/请求水位/额度数学核心，使用 TypeScript 生产编码帧检验字节互通。
- Python 独立计算的 v2 transcript/方向派生/BIP143 向量；新版规范、SDK 文档、施工单增量与重连验收边界。

## 实际验证

环境：Node v22.17.0、Python 3.14.0；TypeScript 5.9.3、@noble/curves 1.9.7 固定 lockfile。C++ 使用本机编译器，`-std=c++17 -Wall -Wextra -Werror -fsanitize=address,undefined`。

| 命令 | 实际结果 | 能证明的范围 |
| --- | --- | --- |
| `./scripts/verify-sdk.sh` | v2 Python 向量新鲜度通过；TS build 通过；28 tests passed / 0 failed | 本轮真实 SDK 软件实现与 C++ 主机编译/执行 |
| `./scripts/verify.sh --check` | 旧 0.1 passed=110 / failed=0 / unsupported=4 | 历史基线未回归，不代表新版或产品验收 |

新版覆盖：严格编码负例、最大帧每个切分位置、CRC；RFC5869/X25519/AES-GCM 实际执行、篡改/重放；独立 Python 与 TS 摘要/派生一致；前序/output/sequence/locktime 签名绑定；实际 DER 签名验证；额度等值/超额/增额/跨渠道并发；真文件重载/写入失败；配对拒绝、加密字节管道往返、等待批准期间 query/cancel 可达；旧 Key 关闭、重载旧会话/预占失效与付款 ID 防重放。

WHATWG 字节管道执行两端真实状态机与密码运算，**不是 USB 物理器件实验**。内存存储测试只验证接口与执行规则；文件测试执行真实 I/O，但不是 Flash 抗回滚或真实供电切断验证。测试中的确认回调由用例驱动，不声称屏幕/按钮验收。
