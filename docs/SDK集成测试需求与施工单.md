# SDK 集成测试需求与施工单

日期：2026-10-09。依据用户确认的独立 Web + ESP32 测试方案，不引入 Keymaster/RocKey 产品集成。代码全部在 `Coding/BSV8_VaultLinkProtocol/integration/` 子项目，协议能力在 SDK 自身实现。

## 已冻结需求

1. USB 接口适配属于 SDK：主机 Web Serial、设备 Arduino 串口、有界帧/编码、加密握手、请求状态与断线清理。操作系统 USB 驱动不由 SDK 实现。
2. Web 页面调用真实浏览器 SDK，ESP32 Demo 调用真实设备 SDK；双方合作验证最小 SDK 集成，不复制协议到 Demo。
3. 使用 Microsoft Playwright，默认完整 Microsoft Edge 无头模式，实际枚举/open USB 串口，不替换 Web Serial 或响应结果。
4. 用户插入测试设备后，脚本完成上传及测试。授权决定由测试固件脚本控制，故障点内部重启，不要求手动按键或拔插。
5. 按外部输出计支出，不计矿工费和本人找零；自动额度、App 跨渠道累计、超额拒绝/一次批准/提高当前额度遵循既有支付需求。
6. 断链/重启建立新加密连接；旧 App 授权失效；持久配置保留；未确定执行结果的预占保守保留，不自动补签。
7. 测试只使用公开测试密钥及本地材料，不广播。测试控制编译隔离，不能暴露于生产 SDK。
8. 无设备、失败或 unsupported 不得当作通过。原生互通、浏览器页面、固件构建、真实硬件分开报告。

## 范围与证据

当前目标经典 M5Stack Core ESP32 USB-UART；其他板型未验证。内部重启证明业务持久恢复语义，不证明 Flash 在物理断电写入过程中的电气可靠性，也不证明原生 CDC 桥重新枚举行为。

测试授权脚本不验收 PIN/屏幕/三个按钮；公开测试密钥自动重新解锁不属于产品策略。C++ 当前覆盖 mainnet/App/P2PKH；测试配置控制操作不作为产品配置同步标准。费用池、插件渠道、迁移及其它 Profile 保持未验收。
